                                3第 1 章 · 引言

                                RISC-V IO Mapping Table（RIMT）在基于 ACPI [2] 的 RISC-V 平台上，提供关于 RISC-V IOMMU [1] 以及 IO 拓扑与 IOMMU 之间关系的信息。RIMT 标识出「哪些组件位于 IOMMU 之后」以及「它们是如何连接在一起的」。

                                RISC-V IOMMU 既可以实现为 PCIe 设备，也可以实现为 平台设备。

                                52.1 · RIMT 节点结构类型

                                RIMT 节点结构大体分为两类：一类是实际的 IOMMU 节点结构，另一类是绑定到 IOMMU 的设备的节点结构。设备节点结构又可细分为绑定到 IOMMU 的 PCIe 根复合体与平台设备结构。

                                例如，在一个只有单颗 IOMMU 的系统中，RIMT 应至少包含两个节点：一个描述 IOMMU 本身，另一个描述这颗 IOMMU 之后的设备。表 2 列出了这些结构可能的类型。

                                PCIe 根复合体节点是一个逻辑 PCIe 根复合体，可用于表示：一整个物理根复合体、一个/一组 RCiEP、一个独立 PCIe 设备、或 PCIe 主机桥之后的那棵 hierarchy。

                                8ID 映射结构

                                ID 映射结构提供「设备如何连接到 IOMMU」的信息。设备可由 source ID 原生标识，但平台可以使用重映射后的 ID来标识设备发给 IOMMU 的事务。

                                对 PCIe 设备

                                source ID 是 16 位的三元组：PCIe 总线号（8 位）+ 设备号（5 位）+ 功能号（3 位），合称 Routing Identifier（RID）。

                                • 一段 source ID 范围只能映射到单一 IOMMU。
                                • 若有多个根复合体具有相同的 PCIe 段号，它们的 source ID 范围不得重叠。
                                • 对属于同一 PCIe 段的每个根复合体 ACPI 设备对象，固件必须包含 _DSM（Device Specific Method）的 Function Index 5，用于保留启动配置（如 PCI Firmware Specification [3] 所定义）。该 _DSM 方法必须返回 0，以指示操作系统必须保留固件在启动时分配的 PCIe 资源。

                                对平台设备

                                source ID 是实现特定的 ID，由设备驱动管理。ID 映射数组的每一项，提供从一段 source ID 范围到「IOMMU 输入端将使用的对应 device ID」的映射。示例见第 3 章。

                                表 6 · ID Mapping Structure（ID 映射结构）

                                • Bit 0：ATS Required
                                •   0：设备无需启用 ATS 即可工作。
                                •   1：设备必须启用 ATS 才能工作。
                                • Bit 1：PRI Required
                                •   0：设备无需启用 PRI 即可工作。
                                •   1：设备必须启用 PRI 才能工作。
                                • Bit[31:2]：保留，必须为 0。

                                92.1.3 · Platform Device 节点

                                可能存在通过 DSDT（Differentiated System Description Table）枚举的非 PCIe 平台设备。这些设备在映射表中可有一个或多个 source ID，但它们可以用自己的方案来定义 source ID。因此，这些 source ID 可能仅对该 ACPI 平台设备唯一。这些 source ID 的解读由平台设备的设备驱动负责。
