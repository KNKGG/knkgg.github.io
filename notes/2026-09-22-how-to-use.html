如何使用这个博客

2026-09-22 · 其他

这个博客是纯静态站点,由 GitHub Pages 托管。你不需要任何构建工具或数据库,所有笔记都是普通的 HTML 文件。

目录结构

blog/
├── index.html      # 首页(目录 + 分类 + 搜索)
├── notes.js        # 笔记索引,加笔记时改这里
├── notes/          # 每篇笔记一个 HTML
└── assets/         # 样式和渲染脚本

如何添加一篇新笔记

  1. 在 notes/ 目录下新建一个 HTML 文件,命名 YYYY-MM-DD-标题.html。
  2. 在 notes.js 的 NOTES 数组里追加一条记录。
  3. 提交并推送到 GitHub,自动发布。

分类

分类在 notes.js 的 category 字段维护,可以是「前端」「工具」「读书」等任意中文标签。首页会自动按分类分组显示。
